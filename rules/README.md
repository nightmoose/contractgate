# Agent rules

Copy-paste instructions for coding agents. They say to validate LLM structured
output with AISchemaGate and events at ingestion with DataContractGate.

`.cursorrules`, `CLAUDE.md`, `.windsurfrules`, and `AGENTS.md` are the same
text. Copy the file that matches the tool into the project being edited.

| Tool | File here | Destination |
|---|---|---|
| Cursor | `.cursorrules` | project root `.cursorrules` |
| Claude Code | `CLAUDE.md` | project `CLAUDE.md` |
| Windsurf | `.windsurfrules` | project root `.windsurfrules` |
| Other agents | `AGENTS.md` | project `AGENTS.md` |

This repository's root `CLAUDE.md` is the contributor pointer. The template is `rules/CLAUDE.md`.
